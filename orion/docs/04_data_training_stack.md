## 1. What "clean" means for ORION training data

Any text that came from a model carries that model's terms into our training data. A dataset
may be used for training only if all three of these hold:

1. Its own license permits commercial model training.
2. **Every model that generated any of its text** has terms that allow training other models
   on its outputs.
3. It contains **no closed-model outputs**. OpenAI, Anthropic and Google Gemini terms all
   prohibit using outputs to build competing models.

If a restricted model only assigned labels or quality scores (for example Llama-3-70B scoring
FineWeb-Edu), the dataset is recorded as "label-only, low risk" and allowed.

| Generator terms | Models |
|---|---|
| **No output restriction** | DeepSeek-R1 / V3.x / V4 (MIT; the R1 card explicitly allows distillation), gpt-oss, Qwen3, QwQ, Qwen2.5 ≤ 32B (Apache-2.0), GLM-4.6 / 5 (MIT), Kimi K2 (modified MIT), Apache Mistral / Mixtral, Phi-3 / 4 (MIT), models under the NVIDIA Open Model License |
| **Restricted: excluded** | GPT-\*, Claude, Gemini (no competing models); Llama 3.0 (outputs may not improve other LLMs); Llama 3.1 / 3.3 (a student model must be named "Llama…" and show "Built with Llama"); Qwen License 72B models (must show "Built with Qwen"; 100M MAU cap); Gemma 1–3n (the student becomes a "Model Derivative") |

The data pipeline enforces this rule. Every example carries `source`, `license` and
`generators` fields, and the provenance stage rejects restricted generators before any other
processing.

## 3. Excluded

- **Contains GPT, Claude or Gemini outputs:**
  - Tulu 3 SFT and preference mixes; Dolci-Instruct SFT and DPO
  - UltraFeedback; Skywork-Reward-Preference-80K; NuminaMath solutions (the problems alone are OK)
  - SWE-smith, SWE-Gym and R2E trajectories (the tasks alone are OK); Arena human-preference responses
  - LLaVA-OneVision data; olmOCR-mix; PixMo-cap / docs / cap-qa / ask-model-anything; Molmo2
- **Non-commercial or research-only:**
  - AM-\* distilled sets, KodCode, APIGen-MT, MiroVerse
  - xLAM-60k (card: "research purposes only")
  - DCLM-baseline (card: "not intended for training production-ready models"), which also taints olmo-mix-1124 and Zyda-2
- **Carry restrictive model terms:** Magpie (Llama 3.1 / Qwen2.5-72B), MegaMath synthetic subset, MAmmoTH-VL, FineTranslations (translated by Gemma 3, so any student becomes a Gemma Model Derivative).
- **Card license contradicts the card text:** LLaVA-OneVision (Apache tag, academic-only text).

## 4. Evaluation sets

**Policy:**
- Evaluation data lives only under `evals/`. The data pipeline builds a 13-gram index over every
  evaluation set and drops overlapping training examples.
- Canary-protected sets (GPQA, HLE, BrowseComp) are never copied anywhere else.
- Contamination-resistant or fresh sets take priority.

| Benchmark | License | Use in ORION |
|---|---|---|
| GSM8K-Platinum `madrylab/gsm8k-platinum` | see registry | School math. Replaces saturated and noisy GSM8K test |
| MATH-500 `HuggingFaceH4/MATH-500` | source MIT | Math, with a caveat: memorized by some model families |
| AIME 2026 / HMMT Feb 2026 (MathArena) | CC-BY-NC-SA | Evaluation only (non-commercial); competition math; 30 questions, so high variance |
| MMLU-Pro `TIGER-Lab/MMLU-Pro` | MIT | Knowledge |
